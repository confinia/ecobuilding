À propos d'EcoBuilding

EcoBuilding montre les bâtiments français en 3D, colorés par classe énergie (DPE), à partir de données publiques ouvertes. Aucune brique propriétaire, aucune dépendance à un fournisseur de cartographie fermé : une démonstration qu'une pile cartographique souveraine et gratuite est utilisable aujourd'hui.

Données & attribution

Toutes les données affichées sont ouvertes et attribuées à leurs producteurs. Les vues rendues (cartes, fiches PDF) sont des œuvres dérivées autorisées ; les bases restent sous leurs licences respectives. Une API JSON publique expose la même chaîne de données. Un export GeoJSON par commune permet la réutilisation (uMap, QGIS).
